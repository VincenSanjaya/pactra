Pactra v0.1

Project Name:
Pactra

Tagline:
Work. Verify. Get paid.

Problem:
Freelancers risk not getting paid after completing their work. Clients risk paying before receiving acceptable results.

Solution:
Pactra is a milestone-based onchain escrow system where USDC is locked in a smart contract and released when work is approved.

Target Users:
Freelancers and clients working on digital projects.

Core Features:

1. Connect wallet
2. Create Pact
3. Assign freelancer
4. Create milestones
5. Fund escrow
6. Submit milestone
7. AI-assisted review
8. Approve or request revision
9. Release payment

Blockchain:
Arbitrum Sepolia

Payment:
Mock USDC for MVP

Frontend:
Next.js

Smart Contracts:
Solidity

Wallet Integration:
wagmi + viem

AI:
API-based work review

MVP Demo Scenario:

Client:
Alice

Freelancer:
Bob

Project:
Build Pactra Landing Page

Total Payment:
1000 USDC

Milestone 1:
UI Design
300 USDC

Milestone 2:
Frontend
400 USDC

Milestone 3:
Deployment

Main Demo Flow:

Alice creates a Pact
→
Alice funds 1000 USDC
→

→
